# CoinWake

Crypto price alert app with portfolio tracking and profit calculator.

## Structure
- `backend/` - Express.js API with MongoDB
- `frontend/` - TanStack Start + React + Capacitor

## Development
```bash
npm install
npm run dev
```

## Deployment
- Backend: Render (see backend/render.yaml)
- Frontend: Vercel
- Mobile: Capacitor (iOS/Android)
